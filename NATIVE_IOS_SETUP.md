# Native iOS Setup

## Prerequisites

1. **Xcode** (27.x used here) with the iOS platform installed, and the command-line tools pointed at it:
   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   ```
2. **Node 22** and **CocoaPods** (Expo runs `pod install` for you).
3. `ios/` is generated by `npx expo prebuild`. **Don't edit it by hand**; configure through `app.json`, config plugins and `modules/`, so it can be regenerated with `npx expo prebuild --clean`.

## Native pieces

| Piece | Technology | Where |
| --- | --- | --- |
| Home and Lock Screen widget "MyOrbit Today" | `expo-widgets` (SwiftUI from JSX), WidgetKit target `ExpoWidgetsTarget` | `src/widgets/TodayWidget.tsx`, `app.json` |
| Timer Live Activity and Dynamic Island | `expo-widgets` `createLiveActivity`, ActivityKit. The countdown is SwiftUI `Text(timerInterval:)`, so it keeps ticking while the app is closed. | `src/widgets/TimerActivity.tsx`, `src/services/liveActivitySync.ts` |
| Shared data | App Group `group.com.daypilot.personal`; the app writes a small snapshot, the widget never opens SQLite | `src/services/widgetSync.ts` |
| Local reminders | `expo-notifications` (local only, no push entitlement) | `src/services/reminderSync.ts` |
| Backups | `expo-file-system`, `expo-sharing`, `expo-document-picker`, `expo-crypto` | `src/services/backupFiles.ts` |
| Siri / Shortcuts | App Intents in the main app target, added on `prebuild` by `plugins/withAppIntents.js` from `plugins/app-intents/MyOrbitIntents.swift`. Intents queue a small JSON action in the App Group; the app applies it on next open (`src/features/intents/intentActions.ts`). | `plugins/` |
| Widget tick buttons | `expo-widgets` buttons; a tick updates the widget immediately and is completed in SQLite when the app next opens | `src/widgets/TodayWidget.tsx`, `src/services/widgetSync.ts` |
| Personal AI | Local Expo module `modules/myorbit-ai` (Swift) using Apple **FoundationModels**, iOS 26+. The framework is weak-linked and every call is behind `#available(iOS 26.0, *)`, so the app still runs on iOS 17–25 with the AI hidden. | `modules/myorbit-ai/ios/MyOrbitAIModule.swift` |

Configuration in `app.json`: bundle identifier `com.daypilot.personal` (kept from the original project so existing data, the App Group and the widget keep working), display name **MyOrbit**, deployment target iOS 17.0, iPhone only, `NSSupportsLiveActivities`, Face ID usage text.

## Installing on your iPhone

1. Connect the iPhone with a cable and unlock it. Tap **Trust** if asked.
2. Open the workspace in Xcode:
   ```bash
   open ios/MyOrbit.xcworkspace
   ```
3. Xcode → Settings → **Accounts**: add your Apple ID.
4. Select the **MyOrbit** target → **Signing & Capabilities** → tick *Automatically manage signing* and choose your team. Do the same for the **ExpoWidgetsTarget** target. If the bundle ID is taken, change `ios.bundleIdentifier` in `app.json` to something unique (e.g. `com.yourname.myorbit`), run `npx expo prebuild --clean`, and reopen. Changing it later creates a separate app with separate data.
5. Pick your iPhone as the run destination and press **Run** (⌘R).
6. On the iPhone: Settings → Privacy & Security → **Developer Mode** → on (it restarts). Then Settings → General → VPN & Device Management → trust your Apple ID.
7. For the AI: Settings → **Apple Intelligence & Siri** → on, and let the model finish downloading.

Alternatively, from the project folder: `npx expo run:ios --device` (choose your iPhone), with the Metro server running for development builds.

### Free vs paid Apple account

- **Free Apple ID:** the app runs for **7 days**, then you re-run it from Xcode. Data is kept when you reinstall over it. App Groups may need to be registered by Xcode's automatic signing; if the widget target fails to sign with a free account, the app still works but the widget and timer Live Activity won't.
- **Apple Developer Program** (A$149/year): one-year signing, TestFlight, no 7-day limit. MyOrbit doesn't need push notifications or any paid service.

### Development build vs release build

A **Debug** build loads its JavaScript from Metro on your Mac, so it only works when the Mac is on the same Wi-Fi network. For a build that works anywhere, use **Product → Scheme → Edit Scheme → Run → Build Configuration: Release**, then Run. That bundles the JavaScript into the app.

## Lifecycle rules

- Live Activities stay active up to 8 hours, then remain on the Lock Screen up to 4 more. `activity_sessions` caps sessions at 12 hours. On launch and on foreground the app reconciles: it ends orphaned activities and never creates duplicates.
- Widget refreshes are budgeted by iOS. Widgets reload after data changes (debounced); they aren't real-time.
- iOS keeps at most 64 pending local notifications per app. MyOrbit schedules at most 60 (the soonest two weeks) and re-plans on every launch, foreground and data change.
